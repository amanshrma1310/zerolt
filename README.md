# Zerolt — Next-Gen Web & Marketing Automation Platform

Official website and digital ecosystem for **[Zerolt.com](https://zerolt.com)** — an elite agency specializing in modern CMS architectures (GoHighLevel, n8n, Zoho, Webflow, Shopify Plus, Lovable AI, WordPress, Wix) and launching **LeadSpark**, an autonomous lead workflow and marketing automation engine.

---

## 🚀 Key Features

* **Interactive 3D WebGL Hero Engine**: Three.js-powered geometric automation core with neural particle constellations that react to cursor physics and mobile touch.
* **3D Perspective Tilt**: Depth-layered cards with parallax lighting effects and live animating telemetry charts.
* **Interactive Capabilities Accordion**: Real-time 3D stage switcher showcasing Webflow, GoHighLevel (GHL), n8n, Zoho, and CRO capabilities.
* **LeadSpark Product Spotlight**: Interactive sneak peek of Zerolt's upcoming marketing automation engine, featuring a 4-stage visual pipeline and VIP waitlist capture.
* **Full 4-Page Experience**:
  * `index.html`: Homepage featuring 3D hero canvas, platform marquee, capability accordion, testimonials, and dark footer.
  * `about.html`: Agency narrative, design-plus-automation philosophy, and engineering leadership.
  * `services.html`: Comprehensive breakdown across all modern CMS and workflow engines with deliverables and tech badges.
  * `contact.html`: Interactive inquiry form with multi-platform selector chips, budget tiers, direct calendar booking, and FAQs.

---

## 🛠 Tech Stack

* **Frontend**: Semantic HTML5, Modular CSS3 (Custom Variables, 3D Perspective Transforms, Glassmorphism)
* **3D & Animation**: [Three.js](https://threejs.org/) (WebGL), [Vanilla-Tilt.js](https://micku7zu.github.io/vanilla-tilt.js/)
* **Typography & Icons**: Plus Jakarta Sans (Google Fonts), FontAwesome 6

---

## 💻 Local Preview

Double-click `index.html` or run a local HTTP server:

```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000`.
